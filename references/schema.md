# 《财政项目推进总台账》列结构

## 工作表布局

| 行 | 内容 |
|---|---|
| 第 1 行 | 标题（如 `财政项目推进总台账` / `事项总数 61` 汇总行） |
| 第 2 行 | **表头**（列名） |
| 第 3 行起 | 数据行 |

> 读取时：先定位含「编号」的表头行，再按列名取值（不要写死列号，避免列增删错位）。

## 列清单（14 列）

| # | 列名 | 说明 | 取值示例 |
|---|---|---|---|
| 1 | 编号 | 唯一编号，前缀表类别 | `REQ-01`、`DEV-03`、`ACC-05` |
| 2 | 项目类别 | **筛选键** | `新系统建设` / `原系统开发` |
| 3 | 工作包类别 | **分类键** | 见下方枚举 |
| 4 | 工作包名称 | 甘特图 Y 轴标签 | `提交需求书`、`投产上线` |
| 5 | 里程碑 | 是否里程碑 | `是` / 空（`None`） |
| 6 | 交付成果/验收标准 | 任务描述 | `《需求说明书》确认…` |
| 7 | 主责人 | 负责人 | `杨继丹`、`吕祺` |
| 8 | 协作/前置编号 | `协作方,协作方 / 前置编号列表`，`—` 表无前置 | `对公,运管 / DEV-05` |
| 9 | 计划完成日 | 甘特图右端点 | `2026-10-29`（datetime） |
| 10 | 推进状态 | 状态着色键 | `已完成` / `进行中` / `未开始` |
| 11 | 风险级别 | 风险等级 | `高` / `中` / `低` |
| 12 | 风险/卡点及措施 | 风险描述 | `接口误用、无权限调用…` |
| 13 | 下一步行动 | 计划动作 | `联系供应商…` |
| 14 | 最近更新 | 更新时间 | `2026-11-12` |

## 工作包类别枚举（逻辑顺序，用于图表排序）

`需求与范围` → `方案设计` → `采购` → `开发` → `版本交付` → `测试` → `安全测评` → `环境部署` → `投产验收` → `培训交付` → `合规监管`

> 图表 X 轴 / 饼图按此逻辑顺序排列（不是按数量），更符合项目生命周期；新出现的类别追加到末尾。

## 注意事项

- **编号可能重复**（如两个 `DEV-03`、两个 `DES-01`），区分靠「工作包名称」；甘特图用名称不用编号。
- 「里程碑」列可能存数值（旧版 `0/1/2/3/4`）或文本（新版 `是/空`），判里程碑只认 `== '是'`。
- 单元格可能为 `None`，取值后统一转空串，避免渲染 `None`。
- 台账第 1 行汇总（`事项总数 61`、`已完成 19` 等）仅供参考，统计以实际数据行为准。
